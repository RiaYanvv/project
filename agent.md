# Project Instructions

## Product Role

This project is an AI-powered geopolitical supply chain
decision-support assistant for strategic manufacturing companies.

## Product Principles

- Evidence-based
- Explainable
- Human-in-the-loop
- Decision support, not autonomous decision making

## Architecture Principles

- Keep the architecture simple.
- Avoid unnecessary multi-agent complexity.
- Do not redesign the existing Agent without explicit instruction.
- Frontend and backend should communicate through defined schemas/APIs.

## Frontend Principles

- Professional B2B interface
- Clear information hierarchy
- Evidence and uncertainty must be visible
- Avoid unnecessary animations
- Responsive layout

## Development Rules

- Do not modify backend unless explicitly requested.
- Do not change schemas without checking existing documentation.
- Do not add dependencies unless necessary.
- Use existing components before creating new ones.
- Explain major architectural changes before implementing them.
